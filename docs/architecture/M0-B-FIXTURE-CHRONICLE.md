# M0-B 合成项目来源与观察基础

版本迁移 v2 为明确标记为 fixture 的项目来源与观察记录提供持久化；这不是文件扫描器或真实来源验证。`fixture_sources` 与既有项目及授权范围绑定，`fixture_facts` 保留项目、来源、来源 epoch、幂等键与受严格校验的合成记录。数据库外键、唯一键和触发器限制跨项目关联、重复和事实变更；v1 升级和重复迁移必须保留已有数据。

`src/fixture-chronicle.ts` 在每次合成注册、追加、读取和来源重置时于事务中重新检查数据库中的授权；无授权、撤权、暂停、过期或来源停用时不返回记录。来源 epoch 改变后旧记录保留，但不得经当前读取接口取回。相同幂等键只有在完整内容一致时才允许重放；数据库内容与索引字段不一致时失败关闭。

**边界**：传入的 scope 必须来自未来已认证的服务端上下文；principal ID 自身不是认证。fixture 中的文本与 `tool_observed` 标签是合成测试数据，不证明模型或真实项目事实；该模块不读取任何用户项目。真实目录仍需要项目生命周期、可信范围、竞态安全读取、撤权后的缓存使用策略及安全 Gate。观点版本、反馈和真实来源一致性仍待后续实现。

验证命令及结果见 `handoff/EVIDENCE/m0b-fixture-chronicle-check-2026-11-03.txt`。本轮采用纯合成目录和 SQLite；Windows 尚未实机验证，M0 Gate 仍未通过。
