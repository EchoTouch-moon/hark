## What the tests actually did

Synthetic temp directories only. No Home scan, no private vault, no picker, no model, no network provider.

- Forged path, success, approved, risk, completed, and relativePath are rejected by serde before Core.
- Unknown, expired, and replayed pick tokens do not authorize. A symlink directory is `symlink_rejected` and the token is consumed.
- Selected sibling candidates confirm into two workspaces. Root-plus-child is `overlap_refused`. A forged candidate id is `candidate_not_in_scan`.
- Local card is `local_scan_card`, onboarding is `waiting_for_model_auth`, `modelAnalyzed` stays false, and no `agent_opening_message` is stored.
- Reopening the same sqlite restores roots, the local card, and the user note.
- Pause blocks scan; a pre-cancelled scan cannot be confirmed; revoke blocks a new read and keeps the conversation.
- Source fixture bytes were unchanged. `.env` and `node_modules` appear in scan ignored, not as source excerpts.

## Same-key cancel flag

P1: a second `scan_root` / `selective_key_read` for the same root or workspace replaced the `CancelFlag`, and the first finisher's `remove` could drop the other task's flag. Tauri marks those commands `async`, so the threadpool can overlap them.

Fix: under the same map lock, an occupied key returns `scan_already_running` or `read_already_running` and does not overwrite. The lease drops only its own `Arc`. Busy is not success and is not `scan_not_running` / `read_not_running`. No generation table.

Negative test first, synthetic temp dirs only, condvar barrier, no sleep. Before the occupancy check:

```text
cd apps/desktop
set -o pipefail
cargo test -p hark-native-shell --test flow overlapping_ -- --test-threads=1
TEST_EXIT:101
2 failed; 0 passed; 7 filtered out
overlapping scan_root returned success; it replaced the running cancel flag
overlapping selective_key_read returned success; it replaced the running cancel flag
```

After the fix, same filter:

```text

2 passed; 0 failed
```
