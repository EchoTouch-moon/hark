# M1-A A-C3 独立定向复审 R2：BLOCKED

审查基线 `c75ec0e`（产品代码 `471092f`），macOS Darwin arm64，Node 22.23.2、pnpm 11.9.0。范围为首轮五项缺陷、受影响路径及回归；仅使用自建合成临时数据。结论：**不得关闭 A-C3 或标记 M1-A 通过**。原修复针对原复现有效，但下面两个可复现的问题仍影响已启用的项目授权和撤权边界。

## P1：目录替换后 A 的授权可读取 B 内容

位置：`src/fixture-discovery.ts:326-365`。`projectReadAllowed` 检查数据库中的 candidate 状态与字符串路径前缀；逐层 `openChild` 获得的目录身份没有与该 candidate 的 `binding_dev`/`binding_ino` 比较，读取后的复核仍只检查数据库。

实际时序：1）在同一合成根中创建 A 和 B 并枚举；2）只为 A 发放项目读取 scope；3）把 A 目录移开，再将 B 目录改名为 A，**没有重新枚举**；4）以 A scope 读取 `project-a/data.txt`，返回 B 的独有合成内容 `SYNTHETIC_B`。这是已实现的跨项目 scope 失效；未涉及真实目录，也未声称当前已存在远程 API 漏洞。实际输出见 `handoff/EVIDENCE/m1-a-c3-r2-2026-11-04.txt`。

修复需将实际打开对象与候选身份及当前授权绑定，且处理目录在读取期间或逐层打开期间被移动、替换的情况；只比较一次 inode 不能证明后续读取仍在允许范围。检查前后重新验证也不能单独保证中间没有发生过越界读取，须证明所用受控能力的竞态语义，无法证明时关闭受影响读取或改用不开放文件系统读取的受控合成数据适配器。修复后用两项目不同标记、替换/移动、撤权及重启负例验证，不能只断言结果被过滤而忽略越界读取已发生。

## P2：撤权后保存的原始 fd 数字可指向另一根

位置：`src/fixture-discovery.ts:49` 暴露数值句柄；`src/posix-dir-handle.ts:23,76-78,98-104` 仅以当前 `Set<number>` 判断所有权。复现时保存根 A 的 descriptor，撤销 A，随后打开 B；本机系统复用了相同 fd 数字，传入此前保存的数字调用公开的 `listDirectory`，返回根 B 的目录项。该复现依赖同进程持有原始 fd 和 B 后续被打开，不声称存在已接入的外部端点。它直接说明首轮要求的不透明句柄及撤权后底层能力封闭仍未成立；原测试只在 fd 复用前检查一次。

建议取消对外暴露原始数字，并让适配器校验与具体根及生命周期绑定的不可伪造句柄；撤权后旧句柄不能因 OS 数字复用重新指向其他根。添加 fd 复用回归，覆盖旧句柄的 list/open/read/close 及新根不受影响；仅检查 `owned.has(fd)` 不足。

## 原五项的定向结果

1. 项目观察 grant：无 grant 的原例拒绝，但上面的替换负例显示 scope 未绑定实际打开项目，**未通过**。
2. 外部硬链接：原复现和现有自动测试拒绝 `nlink != 1`，在本次场景 **通过**；不代表能证明全部目录移动边界。
3. 原生加载：源码不再运行时调用 `cc` 或加载临时缓存；`pretest`/`prebuild` 编译到仓库内 `build/`，原场景 **通过**。此结论不代表针对恶意同用户进程的完整隔离或其他平台验证。
4. 撤权：原测试场景下关闭句柄、SQL 撤权不可回滚；fd 复用负例仍可操作另一根，**未通过**。
5. 同 inode 目录移出再返回：原复现及自动测试返回相同 candidate，**通过**；不替代不同 inode 替换的负例。

- 两个负例以临时合成数据在本机执行，不修改真实项目或访问私人目录；以下脚本可在完成 `pnpm build` 后从仓库根执行并自清理。断言命中缺陷时退出 0，仅用于重现当前问题，不是修复后的通过标准。

```bash
node --input-type=module <<'NODE'
import {mkdtempSync,mkdirSync,writeFileSync,renameSync,rmSync} from 'node:fs';
import {tmpdir} from 'node:os';
import {join} from 'node:path';
import {beginSyntheticRoot,enumerateSyntheticRoot,issueSyntheticProjectRead,readSyntheticFile,revokeSyntheticRoot} from './dist/fixture-discovery.js';
import {listDirectory} from './dist/posix-dir-handle.js';
import {openDatabase} from './dist/storage.js';
const scratch=mkdtempSync(join(tmpdir(),'hearth-ac3-r2-'));
const now=new Date('2026-11-04T12:00:00Z'), expires='2099-01-01T00:00:00Z';
const db=openDatabase(join(scratch,'demo.sqlite'));
const a=beginSyntheticRoot(), b=beginSyntheticRoot();
try {
  for (const [name,value] of [['project-a','SYNTHETIC_A'],['project-b','SYNTHETIC_B']]) {
    mkdirSync(join(a.setupPath,name));
    writeFileSync(join(a.setupPath,name,'PROJECT.md'),'synthetic');
    writeFileSync(join(a.setupPath,name,'data.txt'),value);
  }
  const ar=a.commit(db,now,expires);
  if(ar.status!=='available') throw Error('adapter unavailable');
  try {
    const scan=enumerateSyntheticRoot(db,ar.handle,now);
    if(!('candidates' in scan)) throw Error('scan unavailable');
    const candidate=scan.candidates.find(x=>x.relativePath==='project-a');
    const issued=issueSyntheticProjectRead(db,ar.handle,candidate?.candidateId,now,expires);
    if(issued.status!=='available') throw Error('grant unavailable');
    renameSync(join(a.setupPath,'project-a'),join(a.setupPath,'parked-a'));
    renameSync(join(a.setupPath,'project-b'),join(a.setupPath,'project-a'));
    const result=readSyntheticFile(db,ar.handle,issued.scope,['project-a','data.txt'],1024,now);
    const leaked=result.status==='available' && result.bytes.toString()==='SYNTHETIC_B';
    console.log(`A scope returned B content: ${leaked}`);
    if(!leaked) throw Error('replacement defect did not reproduce');
    const saved=ar.handle.rootDescriptor();
    revokeSyntheticRoot(db,ar.rootId,ar.rootEpoch,now);
    mkdirSync(join(b.setupPath,'synthetic-b'));
    const br=b.commit(db,now,expires);
    if(br.status!=='available') throw Error('second adapter unavailable');
    try {
      const observed=listDirectory(saved);
      const reused=br.handle.rootDescriptor()===saved;
      const leakedNames='names' in observed && observed.names.includes('synthetic-b');
      console.log(`fd reused: ${reused}; revoked descriptor lists B: ${leakedNames}`);
      if(!reused || !leakedNames) throw Error('descriptor reuse defect did not reproduce');
    } finally {br.handle.release();}
  } finally {ar.handle.release();}
} finally {
  db.close();
  rmSync(a.setupPath,{recursive:true,force:true});
  rmSync(b.setupPath,{recursive:true,force:true});
  rmSync(scratch,{recursive:true,force:true});
}
NODE
```

描述符复用依赖操作系统分配，若复用未发生应报告未复现，不得据此断言缺陷不存在。
