# 保留轻形态，以“拾回旧念头”建立记忆点

用户认可无工作台框架的轻量布局，同时指出项目缺少独特记忆点。本轮保留已认可布局，仅增强核心项目记忆的表达。

## 一处签名

在Agent开场前放一枚“记忆折页”：项目名、历史日期和一句旧念头。其内容来自当前示例项目的idea与记录日期，不使用通用励志语或装饰性数字。页形标记同时用于小型品牌字标前，建立重复识别。

折页默认收拢，只占一小块内容。点开或键盘Enter可以在原处读完整旧念头、已有材料和未知部分，收起即可继续聊；没有新增侧栏、仪表盘、来源弹窗或流程步骤。换到另一个项目时折页对应换项目，全部发现暂缓且无项目范围时不强造一条记忆。长对话中它作为开场随消息滚走，不持续抢占输入。

设计重点是“这个Agent记得我做过什么”。它属于核心记忆功能的表达增强，非新增后台记忆系统；不扩展扫描、研究或执行权限。当前所有记忆依然是标明的合成资料，日期为示例记录。页形标记为几何SVG，不加载位图、动效依赖或声音。

## 形态

原有纸白、深绿、安静单列不变。记忆折页使用已有灰紫便笺色；正文引用采用已有中文衬线，项目/日期小型无衬线。主讨论保持平面文字，折页以“旧材料”的身份区分过去与当下。展开使用原生details，不延迟，也不进行翻页动画。
