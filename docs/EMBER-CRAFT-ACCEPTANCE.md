# Ember 精修验收 · 2026-10-30

本次用户指出上一版火焰、开屏和生命周期转场精细度不足。验收以实际浏览器和可操作组件为依据，不能以“有动画属性”替代视觉验收。

| 表面 | 可观察的标准 |
| --- | --- |
| 炉心 | 不对称火舌、尖端曲率、通透内焰、炭心结构、接触光；缩小后仍有独特轮廓；不能是圆形叠加 |
| 三态 | 黯的炭心微光、温的稳定单焰、旺的多火舌，在静帧也能分辨；布局和文字可读性稳定 |
| 运动 | 各火舌不同相位、以根部为原点、呼吸克制；点燃先芯后焰，复燃有连续过程 |
| 开屏 | 字标、炉心、邀请同属一个画面；无倒计时和强制观看，随时可继续/跳过 |
| 初始化 | 可选称呼，不索取密码/邮箱；明确本地偏好与离线演示；返回不丢草稿 |
| 进入 | 欢迎文字退场、炉心和对话主轴衔接、输入接焦点；不把初始化当聊天成功 |
| 再访 | 不重复欢迎、不重新点燃；可重看开场，恢复既有真实对话 |
| 聊天 | Composer、chips、消息和小卡共享间距/材质，最多两主动作；错误和Mock标记清楚 |
| 交互 | 键盘可完成；中文输入法Enter不误提交；减少动态效果可读；手动暂停/后台停止循环 |
| 桌面 | 1440×900 / 1280×800 欢迎操作完整可达，长历史不把输入推走；不新增手机页面 |

验证脚本与图片/视频放在 `handoff/EVIDENCE/ember-craft/`。自动检查只能证明行为和布局约束；具体美感须结合真实截图与录屏判断。产品没有真实账号注册后端，本次欢迎初始化不会声称已注册账户。真实故事卡、远程模型和授权管线保持既有范围。

## 本轮实际结果

- 50项适用单元/服务回归通过；完整日志 `handoff/EVIDENCE/ember-craft/regression.log`。
- `browser.log` 包含欢迎、称呼返回保留、进入焦点/不升温、重看/跳过、失败草稿、确认点燃、实际GSAP路径采样、暂停稳定、1280桌面、reduce、存储失败临时进入检查。
- `keyframes.log` 对应三态实际组件；`flame-*-detail.png` 是浏览器放大当前compact组件以检查真实轮廓，不是正常页面布局截图；时间通过合成历史响应构造。
- `01-arrival.png` 至 `08-storage-unavailable.png` 为桌面真实截图；`full-flow.webm` 为全流程录屏，`motion-preview.webm` 为前15秒片段。
- UI动效使用实际安装的gsap/@gsap/react，不是只引用技能名称。SVG火舌与文字输入转场可在浏览器直接观察。首轮GSAP退出递归已修复并复测，不留为已知故障。
