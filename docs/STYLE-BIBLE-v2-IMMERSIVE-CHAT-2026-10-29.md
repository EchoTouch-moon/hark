## 1. 信息架构（结构优先）

| 层 | 内容 | 出现条件 |
|---|---|---|
| 画布 | 持续对话（消息 + 底栏输入） | 始终；默认几乎全屏 |
| 行动层 | 同条消息内：一句摘要 + 1–3 ActionChip/Card | 仅「有值得关注」时由 Agent 冒泡；否则不出现 |
| 确认层 | 同屏 Sheet（影响范围 / 批准拒绝） | 点行动且需授权时 |
| 进度层 | 同线程内嵌 ProgressBlock（步骤/结果） | 执行中→终态 |
| 侧栏 | 极窄：线程列表（项目=线程）+ 设置齿轮 | 默认可收起；展开宽度 ≤200px |
| 遗留 | `/cards` Insights Activity | **无日常入口**；调试 URL 可留 |

路由建议：`/` = 画布；`?thread=` 或 `/t/:id` 切线程；`/settings` 仅角落进入。

## 2. 主屏流程

```
打开
  ├─ 无未处理建议 → 安静空画布 + 输入焦点（可一句弱提示，非卡墙）
  └─ 有未处理建议 → Agent 消息：摘要一句
                      └─ 下方 1–3 Action（主按钮文案=动词：诊断 / 批准 / 查看）
用户点 Action
  → 需授权：同屏 ConfirmSheet → 批准后执行
  → 不需：直接执行
  → 同线程回写 ProgressBlock → 终态结果（失败给原因，不跳页）
切项目 = 侧栏点另一线程（整画布换历史，不进项目后台）
设置 = 侧栏底或顶栏 ••• → Settings（离开感要弱：Sheet 优先于整页）
```

## 4. 组件规格

### CanvasShell
- 无 NavRail 六项；无线条「工作区 / 面包屑」主顶栏
- 背景：`--color-bg` 暖纸；消息列居中 `max-width: 720px`
- 动效：侧栏收展 200ms transform；消息入场 translateY 8px + fade

### ThreadRail（可收）
- 仅：品牌小标、线程名列表（当前高亮 inset accent）、底设置图标
- 线程行：名称 + 可选一行预览；**无** Insights/Activity/建议 Tab
- 收起态：只留窄条图标或全隐

### AgentTurn（有事时）
- 正文：≤3 行摘要（`--text-lg` 可读，勿堆日志）
- Actions：同气泡下方横排或竖排，最多 3；按钮用动词；次要「忽略」文字链
- **不是**整张旧 ActionCard（无 TTL/风险色条堆砌）；风险用一行小字

### ConfirmSheet
- 半高 Sheet：要做什么、影响范围、批准 / 拒绝
- 焦点陷阱；Esc=拒绝默认（与现安全合同一致处保留）

### ProgressBlock
- 嵌在该轮消息下：步骤名（无 secret）→ 成功/失败
- 终态留在线程；「查看原始证据」折叠，不跳 Activity 首页

### Composer
- 底栏 sticky；大输入；无「发送中永转圈」
- 占位偏生活：`你想先处理什么？`（少技术腔）

### QuietEmpty
- 无卡、无 Demo 大按钮墙；一行淡字可选：`有需要时我会出现`
- 首次无仓库：用对话气泡或一次 Sheet 引导，不逼进 Projects 页

## 5. 令牌

沿用 `tokens.css`（暖纸 / 炭火 accent / 10–16 圆角 / 160–220ms）。  
本拍 **不换肤**；Hark 感来自结构与节奏，不是天空背景复刻。

状态色仅用于行动结果与确认风险，不在主壳撒徽章。

Mock：角落小点或设置内标识即可；**禁止**顶栏大条「Chat · Mock / 离线演示」当主视觉。

## 6. 状态矩阵

| 情况 | UI |
|---|---|
| 无事 | QuietEmpty + composer |
| 有事 | AgentTurn 摘要+≤3 行动 |
| 确认中 | ConfirmSheet |
| 执行中 | ProgressBlock 更新；composer 可继续打字 |
| 失败 | 线程内红/墨说明 + 可重试（若安全） |
| 侧栏收 | 画布全宽 |
| 切线程 | 瞬切历史；未完成确认 Sheet 先关闭或随线程走 |
