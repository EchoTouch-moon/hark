## 1. 方法与口径

对每个 PR 取其 `base.sha` / `head.sha` 实际对象，用 **blob 哈希**把 PR 的每个改动文件与当前 HEAD 同路径比较，得到三类：

- `identical`：PR 中该文件内容与 HEAD **完全一致** → PR 在这条路径上已无新增量；
- `differs`：同路径但内容不同 → 需要判断是「PR 更新的独有改动」还是「HEAD 已在其后演进」；
- `absent`：HEAD 没有该路径 → PR 新增文件或已被删除/改名。

这条口径是**文件级**而不是整包 diff：内容一致的路径不构成合并理由，只有 `differs` 且确认 HEAD 缺失的语义才可能是真正增量。

