# Hearth 交互逻辑 v2（草案 · 待用户锁定）2026-10-29

对照 [Hark Using](https://hark.com/using-hark) 公开模型：**单条持续对话**；Home = Action Buttons + Panels；Projects = 主题线程；不是多页工作台。

本轮已交付的「对话主壳」仍是：左栏多路由 + 页头徽章 + 次级列表页——**工作台壳换默认页**，所以看起来普通。下面先定逻辑，再重画壳。

## 锁死的五条（请勾选）

1. **一屏一线程**  
   默认几乎全屏是持续对话。用户主要动作只有：看、说、点行动。不把 Insights / Activity / 建议卡列表当成日常主路径。

2. **Home = 行动层，不是控制台**  
   「现在该做什么」以 **Action（一键解决）** 和可选 **Panel（小块活数据）** 出现——挂在对话顶条或嵌进消息流，而不是独立 Dashboard 页堆卡片。没价值时整层沉默。

3. **闭环发生在线程里**  
   问 → 摘要/建议 → 点行动 →（需授权则同屏确认）→ 执行进度/证据仍在同一线程展开。禁止「去某某页处理」。

4. **Projects = 换一条对话**  
   项目是主题线程（空白或聚焦上下文），不是 CRUD 项目后台。登记仓库等属设置/首次引导，用对话或轻量 sheet 完成。

5. **设置退场**  
   设置、连接、隐私确认进角落入口；不与对话并列抢注意力。

## 明确不做（本拍）

- 不像素复刻 Hark 天空背景/品牌资产  
- 不把本地观察器改成云端 Handoff 等价物  
- 不先做视觉换肤而不改上述结构
