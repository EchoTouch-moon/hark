# 真实建议价值基线

目标30条人工标注，至少两个真实项目。当前仅收录此前用户触发的真实pindou Run的6条建议，0条人评；不生成假建议、不用模型或工程测试冒充人类评价。R2价值门禁未通过。

编辑 recommendation-ratings.json，每条 humanRating 填：

```json
{"rater":"评价者标识","ratedAt":"2026-10-29T08:00:00.000Z","accurate":true,"actionable":true,"useful":true,"noise":false,"note":"具体价值或问题"}
```

运行 `pnpm exec tsx scripts/score-recommendations.ts`。不足30条返回 NOT_MEASURED 和 exit 2；报告有用建议占比与噪声率，不推断不存在的人评结果。采样应覆盖不同状态与失败/无建议结果，避免只收集成功好例；新真实调用需由用户在预览界面触发。

2026-10-29 人工定性反馈已原样记录：现有建议方向过于集中于本地构建/检查，用户更需要核对项目发展与演进；本地建议可保留，整体应更多元。上次问卷展示的是压缩摘要，原始完整文本保留在样本detail。该反馈未被擅自映射为每条 useful/noise 分数。

后续逐条评价维度：目标与用户价值、阶段成果与目标偏差、已有证据支持的演进路径、下一步优先级、工程健康与验证。无证据时记录信息缺口；不要求每张卡覆盖所有维度，不为凑多样性虚构路线图。当前能力只读有限文档，定向代码上下文仍归P2-B候选，不抢跑。
