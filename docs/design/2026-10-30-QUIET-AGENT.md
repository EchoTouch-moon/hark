# 从工作台退到一段对话

用户反馈“还是太像一个工作台”。本轮对同一独立原型继续精简，核心问题是管理框架仍占据主视觉：侧栏、项目计数、范围标题、建议卡都让用户先看到系统结构。

本轮把首屏组织为一句具体项目发现与输入框的一组关系。去掉常驻侧栏、项目列表、面包屑、范围标题与计数，撤下独立操作卡片；顶部只保留小字标、项目入口、设置和主题。页面不再自称工作空间，Agent直接从一个具体项目开始说话。

首屏开场与输入在视口中部相邻。有历史后变成正常对话阅读，消息区独立滚动，输入仍可达。项目对象在输入框底部切换，不重复标注“讨论范围”；可访问名称保留。具体项目的档案按需打开，主画面不陈列材料。

功能仍可用：全局/项目独立对话和草稿、刷新恢复、发现进入对应项目、展开依据、暂缓/恢复、项目库、授权演示和设置。入口收起，功能不丢失。原型披露集中在输入下方，实际仍为合成资料、预设回复；正式应用和后台能力未变。
