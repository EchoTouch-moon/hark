# Hearth MVP · 产品意图入口

Hearth 是本地优先的项目助手：用户授权目录后，逐步发现新旧项目，建立分项目记忆，研究公开资料并提出有依据、可修订的判断；用户决定是否执行具体工作。基础多项目与全局盘点属于核心，不局限于 Git 项目。

请先读 [产品需求](../01-PRD.md)、[产品合同](01-PRODUCT-CONTRACT.md)、[重新发现项目的场景](04-PROJECT-REDISCOVERY.md)、[验收场景](03-ACCEPTANCE-SCENARIOS.md) 与 [重建计划](../../tasks/REBUILD-PLAN.md)。历史架构和计划是待评估的参考，不表示当前能力或真实验收通过。

授权观察不等于授权外发、通知或执行；各项许可与预算分别控制。项目安全合同和 AGENTS 指令继续适用，禁用的真实私人目录不得访问。
