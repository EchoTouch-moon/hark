# Hearth Style Bible v5 · Chat First（2026-10-29）

**Verdict：** pass-with-notes（待用户点头 + 产品裁 must）  
**触发：** 用户：逻辑偏复杂、组件太多 → **以对话为主，有需要再出小卡**，对标 Hark。  
**废止主方向：** v4 大决策舞台（证据条常驻、顶栏项目/记录、多 pill 矩阵）。

## Convention
- **保留**暖景气场 + 轻毛玻璃对话台 + 余烬 Send。  
- **打破**大卡工作台感、顶栏双入口、证据条默认展开。  
- **对标 Hark：** 像在聊天；短句；行动是消息下的小按钮；详情按需展开。

## 主结构（极少组件）
1. **Atmosphere** 暖景深  
2. **GlassChat** 单栏对话（品牌耳语 + 可选「线程」一颗弱按钮）  
3. **AgentBubble** 短句  
4. **MiniCard**（仅有事时）标题+一行因由；详情「点开」再展开，默认不堆依据/意见条  
5. **ActionChips** 1 主实心 + ≤2 次幽灵（贴在该条消息下）  
6. **Composer** 凹槽胶囊 + 圆形 Send  

**禁止日常出现：** 项目/记录双 pill 顶栏、大 DecisionCard 证据墙、Orb 大吉祥物占位（可用 28px 小点）、多快捷 chip 墙。

## 流程
无事：气场 + Composer。  
有事：一句摘要 → 可选 MiniCard → 1–3 chip → 点主行动 → 同线程确认/进度短气泡。  
项目切换：一个「线程」入口 Sheet，不是第二套导航。

## 给产品的裁切建议
Must：对话主表面；有事小卡；卡下 CTA；同屏回写。  
Won't：顶栏项目/记录；默认展开证据/意见条；卡墙。
