# 叙事驱动的产品与运动系统

2026-10-30；根 NARRATIVE.md 为核心，本文将其转成实现与验收约束。

## 动机链

用户带来未整理的项目/想法 → 同行者倾听 → 有来源的变化被照见 → 用户选择 → 真实结果回写 → 下次能继续。这条链决定信息何时出现，而非将后台数据排列成仪表盘。当前Mock演示不能跳过事实缺口。

## 动作语汇与实现接口

炉温持久依据仍为服务端用户消息，另设无内容、无权限、无持久化的 visual cue：focus/release/typing/acknowledged/chapter/project-added/declined/failed/motion-preference。cue只负责画面，不可触发模型、后端写操作或审批；不得携带消息正文、路径、称呼或项目ID。

| Cue | 火体 | 环境 | 时间与收尾 |
| --- | --- | --- | --- |
| focus | 内焰展开、向输入区轻倾 | 输入周围反射略收拢 | 180–300ms，不改温度 |
| typing | 低幅短回应，最多每350ms一次 | 一次浅呼吸 | 400–700ms，停止后归位 |
| release | 火尖回自然姿态 | 回到正常光强 | 600ms |
| acknowledged | 确认后点燃由既有scene负责；额外回应不叠加 | 从炉边传到边缘的一次回光 | 800–1100ms，不代表任务执行完成 |
| chapter | 不点燃 | 单次左右侧光交接 | 420–700ms，数据隔离仍由业务负责 |
| project-added | 不持久加热 | 低幅回响 | 真实注册API成功后触发 |
| declined/failed | 回到自然姿态 | 收敛反射 | 错误/拒绝由真实文本表达，不改警报火色 |
| motion-preference | 暂停/恢复 | 暂停/恢复 | 不改变运行/观察/业务状态 |

## 火与空间

三态都有火形运动；黯的短火尖以较慢频率在根部弯折，不能只改煤纹opacity。温/旺通过独立曲率控制点、错相火舌与透光内焰区分。靠近炉心的反应有半径限制和角度上限；鼠标离开回正，不能全屏追随。

页面下缘有来源于炉火的抽象火形与暖反射，侧边火光缓慢伸展；不盖正文，不拦截点击，不伪装第二个主角。读长消息、打开项目/证据页仍能感到同一个空间。

## 实施优先级

本轮完成根叙事重写、火体三态持续运动/靠近响应、全局环境呼吸与cue桥接、现有真实操作反馈。真实StoryEpisode、Pi同线程运行、跨端/账号系统均维持候选阶段，不因本轮视觉工作扩权。

## 验收要证明什么

- 使用真实页面在黯/温/旺分别采样路径或transform变化，暂停后稳定；减少动态效果稳定。
- 靠近有局部响应、移走复位；输入会回应但炉温仍黯。
- 发送失败不播放acknowledged；确认消息保存才播放。
- 切换项目/成功添加对应语义，cue中没有用户内容；不增加API调用。
- 环境呼吸与边缘火形在桌面录屏可见；正文、焦点和输入始终可用。

## 本轮实际落地与证据

- `EmberPresence`：三态均持续非线性曲率流动；独立near/attention/pulse容器分别承接靠近、聚焦和输入，不与自然火形或点燃竞争。离开回正，输入350ms节流，不改炉温。
- `EmberAtmosphere`：底缘6条持续变形火形、纸面呼吸和侧光；捕获focus/input意图但不读取内容，400ms节流；单次回应复用时间线，不叠加亮度。
- AppShell：挂载环境，路由、当前话题及聊天/项目切换触发chapter；项目入口区分谈话与真实本地项目管理。
- ChatPage：确认历史后acknowledged，失败failed，取消确认declined；动效暂停为本次页面会话内的UI偏好，页面内导航保留，整页刷新默认重新开启，系统reduce始终优先。
- ProjectsPage：仅现有注册API成功后project-added，并说明加入观察不等于完成分析/测试。
- 54项适用单元/服务测试通过；新叙事浏览器脚本及原欢迎全流程回归通过。证据目录 `handoff/EVIDENCE/ember-story/`。`living-hearth.webm` 是正常运动、靠近、输入与发送的真实桌面录屏。
- 后台暂停使用浏览器中合成的document.hidden/visibilitychange场景验证，不声称已做OS级省电实验；真实项目注册验收只用本仓库下临时合成Git目录，结束后清理。无远程模型/账号/外部副作用新增。
