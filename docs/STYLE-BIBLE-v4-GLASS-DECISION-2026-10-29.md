# Hearth Style Bible v4 · Glass Decision（2026-10-29）

**Verdict：** **pass-with-notes（方向锁定，待用户点头）**  
**依据：** 用户附图两张——「交互方式应该是这样的」。废止 v3 深色炉火稿作为主方向。  
**Convention：**  
- **打破**死纸 SaaS 聊天、深色终端感、句内下划线当唯一行动。  
- **采用**暖景气场 + **毛玻璃舞台** + **一条决策卡** + 主/次 pill 行动 + 对话气泡续聊。  
- **不**像素复刻附图摄影/吉祥物矢量源文件；结构与材质对齐，资产原创。

---

## 0. 相对产品 v2 must 的对齐

| v2 must | v4 落地 |
|---|---|
| 有事才主动 | 问候摘要 + **至多 1 张** DecisionCard（不是卡墙） |
| 行动留线程 | 卡下 pill → Confirm/执行 → 同舞台回写 Progress/结果气泡 |
| 项目=换线程 | 顶栏「项目」打开**线程列表 Sheet**（非 Insights 工作台） |
| 设置角落 | 记录/设置进角落或 Sheet；**无** cards/insights/activity 日常 Nav |
| 卡流出主路径 | **禁止**多卡 Feed；决策卡是对话里的「这一次」 |

**Note 给产品：** 附图顶栏「项目 / 记录」保留为**弱入口**（Sheet），不恢复仪表盘 Home。

---

## 1. 气质

**窗边晨光里的顾问，不是工单台，也不是暗房聊天。**  
一层毛玻璃浮在暖色景深上；Agent 用短句汇报；真正要你拍板的，只有一张清晰的决策卡。

---

## 2. 舞台结构

```
┌─────────────────────────────────────────────┐
│  [景深 Atmosphere：暖窗光 / 薄雾山色抽象渐变]   │
│   ┌─ GlassStage (圆角 ~28，blur 24–32) ─┐   │
│   │ Brand · tag          [项目][记录]     │   │
│   │ Orb + 问候主句（数字强调色）            │   │
│   │ DecisionCard ×0|1                     │   │
│   │ ActionPills（1 主实心 + ≤3 次描边）    │   │
│   │ 续聊气泡 + 可选快捷 chip               │   │
│   │ ──── Composer 胶囊 ────               │   │
│   └───────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
```

- 默认**无**左侧会话轨占主视野；「项目」Sheet 内才列线程（可保留极弱左缘热区）。  
- GlassStage 最大宽 ~960–1040；圆角大、描边浅白、内高光。

---

## 3. 组件

### Atmosphere
- 暖色景深：晨昏窗光橙 + 远处冷灰蓝；可用 CSS 多层径向渐变 + 极弱噪点。  
- **禁止**整屏 `#f6f4ef` 死纸；**禁止** v3 夜间深墨为主。

### Orb（Agent 在场）
- 小余烬球体（原创，非抄附图矢量）；问候旁出现；续聊用 mini-orb。  
- 不说话时可不出现大 orb。

### Greeting
- 主句 sans 半粗 ~28px；关键数字用 `--color-ember`。  
- 副句弱；时间耳语。

### DecisionCard（有事时唯一主角）
- 白/半透白实卡；**细余烬描边**；圆角 ~20。  
- 区：项目名 +「需要你决定」徽记 → 建议标题（大）→ 原因（小）→ **证据条**（N 证据 / N 改动 / 成员意见）。  
- 不是旧 ActionCard TTL 堆砌；不是 checklist。

### ActionPills
- **1 个**实心主按钮（同意/推进类动词）。  
- ≤3 个幽灵描边次按钮（观察 / 看对比 / 其他）。  
- 可接受 pill——此处 pill 是**决策选项**，不是 v2 陶土筛选芯片三连无主次。

### Progress / 结果
- 仍在同舞台：短气泡或细轨迹；执行完更新卡徽记或收折为结果气泡。  
- Confirm：轻 Sheet 盖在 GlassStage 上。

### Composer
- 底部长胶囊；左✦、中 placeholder、右附件+**圆形**余烬 Send。  
- Send 是舞台上最醒目的持续控件。

---

## 4. 字阶 / 色 / 动效

- 品牌名：衬线；正文：系统人文无衬线。  
- Ember `#E8783A` 系；墨 `#2C2A26`；弱墨 45–55% 透明。  
- 卡入场：120–200ms 上浮 + fade；主按钮 press scale 0.98。  
- `prefers-reduced-motion`：停景深漂移。

---

## 5. 前端 § 落地顺序

1. Atmosphere + GlassStage 壳（替换暖纸 Canvas）  
2. Greeting + Orb  
3. DecisionCard + ActionPills（接现有 proactive/execute）  
4. 续聊气泡 + Composer 胶囊  
5. 项目 Sheet = 线程列表；去掉日常 Nav 六项  
6. 拍屏：安静问候 / 一卡决策 / 执行后结果

---

## 6. 废止

- Style Bible v3 深色炉火作为主视觉（可留文档考古）。  
- v2 陶土实心三连无主次、绿勾 checklist 卡、死纸底。

**设计签名：** 方向按用户附图对齐 → **pass-with-notes**；用户点头后交总工开前端闸。
