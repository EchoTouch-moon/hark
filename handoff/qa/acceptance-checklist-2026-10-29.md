# Hearth 验收清单（对话主壳 · 2026-10-29）

来源：产品需求评审 ready cut。状态：基线观察中；前端/后端交接前不给 pass/fail。

## Must（阻塞发版）
1. 默认落地为对话主壳（或等价），不以建议卡/信息流首页为主入口
2. Insights / Activity / 建议卡列表不当默认主屏；详情/证据可从对话或次级入口进入
3. Agent 对观察与洞察做摘要应答；Mock 须标明；可沿用 `/api/v1/chat`
4. 项目登记、Pi/隐私预览确认、Settings 路径保留，安全合同不削弱

## Should
- 对话内可跳到项目/证据详情
- 空态引导「先登记项目」

## Won't（本轮不验）
- 观察器能力扩展、分析管线本体改动、多端同步、主动推送

## 成功标准（产品）
- 新用户打开先进对话主壳，3 步内能问「现在该关注什么」并得到基于本机事实的摘要（Mock 亦须标明）
- 首页不再并列大量信息流卡片作为主体验
- 敏感外发仍走既有预览确认

## 基线备注（改前）
- 旧绿门（unit/e2e、洞察/Home 卡片）覆盖信息流主路径，不能顶替本清单
- Chat 路由 `adapter: mock` / `live: false`；空心对话本轮可接受但必须标明
