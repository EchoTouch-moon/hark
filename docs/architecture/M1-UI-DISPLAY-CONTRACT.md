# M1 静态展示合同（D-C0）

状态：D-C0 展示合同已由主 Agent 复核；不是服务 API 合同，也不证明 M1 交付。独占 `web/`；直接打开 `web/index.html` 可查看，无网络、文件发现、持久化或模型调用。静态数据是固定虚构样本，观点是示意，不声称真实分析。

## 输入与状态

外壳内部只接受固定样本及展示状态：`overview` 或指定项目；状态 `ready`、`loading`、`empty`、`no-source`、`error`。切换状态仅演示布局。正式集成由 D-C1 定义真实 API 与服务端权限，不得把本地选择器当认证或把此处字段当协议。所有文本必须作为文本呈现，不执行样本内容。

## 展示规则

- 所有视图持续显示「合成演示 / 静态预览」，说明未连接服务、不保存输入、不读取真实项目。全局盘点展示两个虚构项目与单独的未归属项；选择项目只展示该项目内容。
- 项目详情区分目标、成果、待办、来源、示意观点和不确定性；观点引用只指向该项目的虚构材料。演示中的版本、追问与反馈仅为展示，不写入数据或声称已保存。
- `loading` 显示加载提示；`empty` 明确无内容；`no-source` 表示来源不可用且不展示观点；`error` 显示失败且不回退预置项目内容。状态模拟只用于静态外壳展示，不能视为服务失败实测。
- 交互控件必须有名称、可键盘操作和可见焦点；窄屏可滚动。模拟输入可发送以演示对话形态，但回复固定且醒目标记未保存；不表示观点已修订。
- 后续 D-S1 必须以服务端实际结果替换静态数据与状态模拟，按授权过滤项目、来源、对话及版本；服务失败时显示真实错误，不得回退本地样本。反馈、修订及刷新/重启恢复均以服务证据为准。
