# Hearth 验收清单 v5（2026-10-29）· 自有语言 + 空态

状态：**blocked** — 等设计交 Hearth 自有语言 + 空态中心展开关键帧，用户点头；产品 ready 恢复后再开测。v5c「贴 Hark」不算过。

依据：产品「需求补丁 · needs work」+ 总工仿写否决。

## Must（UI/交互）
1. 主表面 = 聊天线程；**自有设计语言**（可借原则，布局/组件/IP 不得复刻 Hark）
2. 顶栏极简：**聊天 | 项目** 分段 + 搜索/头像；无卡墙工作台
3. **空态不空**：无历史时禁止只剩中间空对话框；中心展开 / 情境入场，有呼吸感
4. **对话从中心生长**：消息列居中，自中向外展开，不是贴边工作台框
5. 有事：短句 + 可选 ≤1 小卡 / ≤2 轻 chip；无事不硬塞卡
6. 点行动 → 同线程确认/进度/结果；不跳页
7. 底栏输入；设置 = 头像进玻璃菜单
8. **有趣可续**：至少 1 个可感知吸引点（气场/入场动效/主动短句气质等）；终验用户能说出想再打开的理由

## Won't（出现即 fail）
- 像素 / 布局复刻 Hark；无语言只换皮
- 空态扔空白对话框
- 大决策台 + 证据三列；左栏多面板墙（本拍）
- 顶栏「项目/记录」双按钮堆（非「聊天|项目」分段）

## 后端抽检
- G1–G4 壳仍可：threads / chat / proactive（摘要+可选小卡+≤2 CTA）/ execute 同线程
- 不推「去 Home」

## 成功标准抽检
- 打开不像 Hark 仿写，也不像普通工作台
- 空态有呼吸；有消息后从中心展开
- 组件一眼能数清；有事最多一小卡+两 chip

后拍不挡：左栏 Home 面板、附件/语音、真洞察、e2e、远程推送。
